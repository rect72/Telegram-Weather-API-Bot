# Telegram Weather API Bot

Асинхронный Telegram-бот на Python, который получает актуальную погоду для указанного пользователем города.

Бот определяет координаты города через Geocoding API, запрашивает текущие погодные данные через Open-Meteo API, обрабатывает JSON-ответ и выводит результат в Telegram.

## Возможности

- поиск города по названию;
- получение координат через внешний API;
- получение текущей погоды;
- обработка JSON-ответов;
- отображение температуры, влажности, ветра и погодных условий;
- обработка HTTP-ошибок, таймаутов и некорректных ответов API;
- асинхронная работа с Telegram и HTTP-запросами.

## Технологии

- Python
- aiogram 3
- aiohttp
- python-dotenv
- Telegram Bot API
- Open-Meteo API

## Установка

1. Клонируйте репозиторий.

2. Создайте виртуальное окружение:

```bash
python -m venv .venv
```

3. Активируйте виртуальное окружение.

Windows:

```bash
.venv\Scripts\activate
```

macOS / Linux:

```bash
source .venv/bin/activate
```

4. Установите зависимости:

```bash
pip install -r requirements.txt
```

5. Создайте файл `.env` в корне проекта и добавьте токен Telegram-бота:

```env
BOT_TOKEN=your_telegram_bot_token
```

Не публикуйте файл `.env` и настоящий токен в GitHub.

6. Запустите бота:

```bash
python bot.py
```

## Как работает

1. Пользователь отправляет название города.
2. Бот получает координаты города через Geocoding API.
3. По координатам запрашиваются текущие погодные данные.
4. JSON-ответ обрабатывается Python.
5. Пользователь получает результат в Telegram.

## Безопасность

Секретные данные хранятся в `.env`, который исключён из Git через `.gitignore`.
В репозитории находится только `.env.example` без настоящего токена.
